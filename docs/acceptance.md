# KARI 验证记录 / Validation

**语言 / Language:** [简体中文](#简体中文) · [English](#english)

## 简体中文

当前构建、自动化检查、维护者真机确认及未重复执行的项目，统一记录在[稳定版验证记录](https://github.com/xlle-er/KARI-DF26/blob/main/docs/validation.md)。人工验收应覆盖语音、蓝牙、配网、OTA、运动停止和温升；软件回读不能证明物理停止或所有噪声环境下的识别效果。

## English

See the [stable validation record](https://github.com/xlle-er/KARI-DF26/blob/main/docs/validation.md) for current builds, automated checks, maintainer hardware confirmation and checks not repeated. Physical acceptance should cover speech, Bluetooth, provisioning, OTA, stopping and thermal behavior. Software readback does not prove mechanical stopping or recognition quality in every noise condition.
